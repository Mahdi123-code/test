Adding local repository to Remote repository

Remote Repository:

In Git, a remote refers to a version of your repository that is hosted on a server, typically on platforms like GitHub, GitLab, or Bitbucket Remotes allow you to collaborate with others by sharing your code and keeping track of changes made by different contributors.

  1. git remote add origin https://github.com/username/repository-name.git:
    this is the url of your remote repository
  2. Push code to remote repository
    git push remote-name branch-name:
    Here remote-name is the name of the remote repository that you want to push to and branch-name is the name of the branch that you want to push.
    for example: git push -u origin master
